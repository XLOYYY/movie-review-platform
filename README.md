## 📌 Overview

Movie Review Platform is a full-stack web application that allows users to browse, search, and review movies through a modern web interface.

The project is designed to strengthen my backend development skills by building RESTful APIs, working with relational databases through SQLAlchemy ORM, and developing a complete client-server application.

The backend is built with **FastAPI**, **SQLAlchemy**, and **PostgreSQL**, while the frontend is developed using **JavaScript**, **HTML**, and **CSS**. The project is currently under active development, with new features and improvements being added continuously.
